# 关西餐桌

大阪、京都、神户餐厅的中文静态图文指南，供 2026 年 12 月关西旅行比较餐厅。

- 27 家餐厅，覆盖寿司、刺身、鳗鱼、烧鸟、烤肉、寿喜烧、神户牛、牛排、怀石与居酒屋。
- 支持城市、料理与较晚用餐筛选。
- 图片已嵌入 `index.html`，不需要后端、依赖安装或本地端口服务。
- 使用 Radix Colors，支持明暗主题与手机浏览。

## 使用

直接用浏览器打开 `index.html`，或访问本仓库的 GitHub Pages。

## 信息与照片

餐厅信息、菜单及照片来源链接保留在网页内。价格与营业资料可能变化，请在订位前直接向餐厅确认。评分不代表对未来用餐体验的保证，尚未确认旅行日期空位。

餐厅照片来自各店食べログ页面中的店家或用户投稿，版权归原作者。此仓库不声称拥有这些照片的版权，也不向第三方授予照片的再使用许可。照片是历史或示意内容，不代表所列价格套餐或未来菜单的承诺。

本项目为独立旅行比较笔记，不是食べログ或任何餐厅的官方页面。
